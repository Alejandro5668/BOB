# Errores comunes — NO INYECTAR

SENTINEL: ERRORES_NUNCA_INYECTAR

Catálogo interno de errores comunes reportados por analistas, para
referencia del equipo de soporte. No es documentación de un módulo
específico y NUNCA debe inyectarse como contexto de generación de
descripciones.

Si esta cadena (`ERRORES_NUNCA_INYECTAR`) aparece alguna vez en un
prompt enviado a Groq, hay un error grave de alcance en
`contexto_memoria.py`.
